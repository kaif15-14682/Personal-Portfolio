# Sheikh Kaif – Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, no build step.

## Preview

Open `index.html` in a browser, or in VS Code use the Live Server extension.

## Files

- `index.html` – page content
- `styles.css` – layout and colours
- `script.js` – project filters, tabs, ablation chart, terminal animation and copy-email button
- `assets/profile.jpg` – portrait
- `assets/Sheikh_Kaif_CV.pdf` – optional public CV. The "Download CV" button appears only when this file exists. Remove the phone number, home address and reference contacts before adding it.

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The site goes live at `https://<username>.github.io/<repo-name>/`.
